# Good Prompts

Good prompts for AI coding agents are not long for the sake of being long.

They are clear about goal, scope, constraints, and verification.

---

## Example 1: Bug Fix

Bad:

```text
Fix the profile page crash.
```

Good:

```text
Goal:
Fix the crash when opening the profile page for users without an avatar.

Current behavior:
The page crashes when `avatarUrl` is null.

Expected behavior:
Show the default avatar and keep the rest of the profile page unchanged.

Scope:
Only inspect and modify the profile page rendering path.

Do not change:
- User API response shape.
- Avatar upload logic.
- Routing.

Verification:
Add or update a test for null avatarUrl if possible. Run related tests and typecheck.
```

---

## Example 2: Small Refactor

Bad:

```text
Refactor this module and make it cleaner.
```

Good:

```text
Goal:
Simplify the duplicated validation logic in `OrderForm` without changing behavior.

Scope:
Only refactor validation logic in `OrderForm` and directly related tests.

Constraints:
- Do not change public props.
- Do not change error messages.
- Do not introduce new dependencies.

Verification:
Run existing OrderForm tests. If no tests exist, explain what manual verification is needed.
```

---

## Example 3: Code Review

```text
Review this PR as if it was generated by an AI coding agent.

Focus on:
- Unrelated changes.
- Behavior changes not mentioned in the PR description.
- Missing verification.
- Over-engineering.
- Public API compatibility.

Output:
- Main risks.
- Required changes.
- Suggested improvements.
- Verification gaps.
```

Goal:
